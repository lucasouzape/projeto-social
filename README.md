# Projeto Redes Sociais

Este é um projeto desenvolvido como parte dos desafios do de HTML5 e CSS3.

## 📱 Sobre o Projeto

O projeto consiste na criação de uma interface que simula a tela de um smartphone. Na página principal, há um menu lateral com ícones de várias redes sociais. Ao clicar em um ícone, o conteúdo da tela do celular (um `iframe`) é atualizado para exibir uma página personalizada da rede social escolhida, contendo uma imagem representativa e um link direto para o perfil.

As redes sociais incluídas neste projeto são:
- YouTube
- Facebook
- GitHub
- Instagram
- Twitter 

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica das páginas e uso de `iframe` para a navegação interna da tela do celular.
- **CSS3:** Estilização do layout, interface do smartphone e formatação dos links.

## 🛠️ Como Executar

1. Faça o download ou clone o projeto para o seu computador.
2. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
3. Clique nos ícones das redes sociais no menu para interagir com a página.
